# صيدلية د. هبه الشواربي (Dr. Heba Elshawarby Pharmacy)

تطبيق متكامل وحديث بتقنية **React + TypeScript + Vite + Tailwind CSS** لإدارة وتصفح صيدلية د. هبه الشواربي.

## المميزات الرئيسية (Core Features)

1. **متجر طلب الأدوية للعملاء (Storefront)**:
   - تصفح وبحث فوري بالاسم العربي، الإنجليزي، المادة الفعالة، والباركود.
   - فلترة حسب التوفر و OTC (الأدوية المتاحة بدون وصفة).
   - اختيار وحدات الدواء (علبة، شريط، قرص) مع فحص المخزون الفعلي والأسعار.
   - سلة طلبات تفاعلية وشريط عائم أسفل الصفحة لحساب الإجمالي لحظياً.
   - نموذج استلام الطلب وتوصيله مع تسجيل اسم العميل، الهاتف، العنوان، والملاحظات.

2. **تسجيل الدخول وحسابات العملاء (Customer Auth & Profile)**:
   - تسجيل الدخول وإنشاء حساب جديد بالبريد وكلمة المرور ورقم الموبايل.
   - تخصيص رقم عميل تلقائي لكل مستخدم وربط الطلبات بالحساب.
   - استعادة كلمة المرور وحفظ الجلسة محلياً.

3. **سجل ومتابعة الطلبات (Order Tracking)**:
   - قسم "📦 طلباتي" لمتابعة حالة الطلبات (جديد، قيد التجهيز، تم الشحن، مكتمل، ملغي).
   - تفاصيل الأدوية والكميات والتكلفة الإجمالية وتاريخ الطلب.

4. **دليل البدائل والمثائل الدوائية (Drug Alternatives)**:
   - محرك بحث متقدم يطابق المادة الفعالة (Active Ingredient) والتكافؤ العلاجي.
   - عرض مقارنة الأسعار وحالة التوفر والشركة المصنعة والتركيز.

5. **إدارة مخزون الصيدلية (Inventory Management)**:
   - جدول مخزون تفاعلي يدعم التعديل الفوري لخانات الكود، الباركود، الاسم، السعر، والكميات.
   - دعم كامل لقوارئ الباركود (USB Barcode Scanner).
   - تحديد حد التنبيه للنواقص مع زر مخصص لتصدير وإرسال النواقص عبر WhatsApp للصيادلة والموردين.
   - إضافة وحذف أصناف جديدة وحفظها محلياً.

6. **قسم المستحضرات والتجميل (Cosmetics & Skincare)**:
   - مستحضرات العناية بالبشرة والشعر والترطيب والوقاية من الشمس مع الفئات والأسعار.

7. **لوحة تحكم الطلبات الواردة (Pharmacist Order Management)**:
   - استعراض جميع طلبات العملاء وتحديث حالاتها والتواصل مع العميل عبر الهاتف.

## التشغيل والتطوير (Development)

```bash
# تثبيت الاعتماديات
npm install

# تشغيل خادم التطوير
npm run dev

# بناء النسخة الإنتاجية
npm run build
```
